# 🛰️ La Station Spatiale

Base orbitale de création de **Célestin** et **Maxence** : un endroit où l'on crée des projets à deux, à partir de rien, juste pour le plaisir d'inventer et de construire ensemble.

## La bible

Tout est expliqué dans `index.html` : c'est la bible de la Station. Elle s'impose à tous les projets, à Célestin, à Maxence et à Claude. Elle ne change que si les deux le décident ensemble.

> ⚠️ Sur GitHub, cliquer sur `index.html` montre seulement son code : GitHub n'affiche pas les pages web.

**Pour la lire :**
1. Récupère le dépôt sur ton ordinateur (voir « Rejoindre la Station » plus bas), ou mets-le à jour avec `git pull`.
2. Dans le dossier `station-spatiale`, **double-clique sur `index.html`** : la page s'ouvre dans ton navigateur.

Il faut Internet pour la scène 3D (vaisseau, Terre, étoiles) ; sans connexion, le texte reste lisible.

## En bref

| | |
|---|---|
| **Équipage** | Célestin et Maxence, à égalité |
| **Idées** | [`idees.md`](idees.md), une ligne par idée |
| **Projets** | un dossier par projet dans [`projets/`](projets/), avec son `README.md` |
| **Branches** | `celestin/…` et `maxence/…` ; fusion dans `main` seulement quand les deux sont d'accord |
| **Secrets** | jamais dans le code : uniquement dans les secrets GitHub |
| **Claude** | [`CLAUDE.md`](CLAUDE.md) lui demande de suivre la bible |

## Rejoindre la Station

```bash
git clone https://github.com/maxbaco33/station-spatiale.git
```

Puis ouvrir Claude Code dans le dossier `station-spatiale`.
