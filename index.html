Module 02 · La mission

Le principe

Pas de client, pas de délai, pas d'obligation. Une idée nous plaît ? On la construit. Elle ne mène nulle part ? Ce n'est pas grave, on a appris quelque chose. Chaque projet démarre vierge : une page blanche, un dossier, et l'envie de voir ce que ça donne.

On est deux à égalité. Personne n'est le chef, chacun peut proposer, coder, tester et dire franchement ce qu'il en pense. On s'aide d'outils comme Claude Code pour aller vite, mais les idées et les choix restent les nôtres.

Module 03 · Séquence de lancement

Comment on fonctionne

  1. T-4

    Une idée

    N'importe lequel de nous deux la propose, en une phrase. On l'ajoute à la boîte à idées.

  2. T-3

    Un dossier vierge

    Si on se lance, on crée un dossier dans projets/, avec un petit README.md : ce que c'est, pour qui, ce qu'on veut voir marcher en premier.

  3. T-2

    Un dépôt partagé

    Tout vit dans un dépôt GitHub privé dont on est tous les deux collaborateurs. Chacun peut y travailler quand il veut, de chez lui.

  4. T-1

    Chacun sa branche

    On travaille chacun sur une branche à son nom (celestin/…, maxence/…). Comme ça, personne ne casse le travail de l'autre.

  5. T-0

    On montre, on fusionne

    Quand quelque chose marche, on le montre à l'autre. Si on est d'accord tous les deux, on le fusionne dans main. Décollage.

Module 04 · Règlement de bord

Les règles d'or

RÈGLE 01

Pas de pression

Chacun avance à son rythme. Un projet peut dormir des semaines et repartir.

RÈGLE 02

On ne casse rien chez l'autre

Branches séparées, et on ne fusionne dans main qu'à deux.

RÈGLE 03

Aucun secret dans le code

Jamais de mot de passe, de clé ou de jeton dans les fichiers. Ils vont dans les secrets GitHub.

RÈGLE 04

On écrit ce qu'on fait

Un README par projet, tenu à jour. Celui qui revient dans trois mois doit comprendre.

RÈGLE 05

Pour nous

Ce qu'on crée ici est pour notre usage et nos proches, pas pour le revendre… pour l'instant ;)

RÈGLE 06

Le droit d'arrêter

Abandonner une idée qui ne plaît plus, c'est permis. On garde le dossier, on passe à autre chose.
